# Image attribution

Every destination photograph is stored locally in `assets/treks/`. The authoritative per-file record is [image-credits.json](image-credits.json): creator, original Commons page, direct download URL, license URL, verified destination caption and review date.

Photographs retain their original licenses. CC BY requires attribution; CC BY-SA additionally requires adaptations of the photograph to use the same license. These licenses apply to the photographs, not automatically to unrelated application code. Preserve the credits when redistributing. Images are Wikimedia-generated thumbnails; the interface scales/crops them for display, without modifying the stored files. CC0 imagery is also credited for provenance.

The original Commons descriptions and file titles were checked against each destination, and all six downloaded images were visually inspected. Everest imagery is specifically Nepal-side; Tibet north-base-camp images were rejected. The Mardi photograph is from the higher base-camp area, not the selected Upper Viewpoint endpoint. The Manaslu photograph is from its base camp, an optional side trip. Captions state those distinctions explicitly.

`photo-review.jpg` is a contact sheet for visual QA containing the same credited images. Each photograph's license remains applicable to its portion of that sheet.
